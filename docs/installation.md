# 网站数据接入

网站设置的“数据接入”统一提供 JS 代码、Cloudflare 授权、服务器安装和继续检查入口。旧追踪代码与控制台检查地址继续打开当前网站的同一套引导。

接入进度通过 `/api/liekan/websites/{websiteId}/installation` 按网站保存。正常前进保存恢复步骤；跳过检查额外记录延后标记；完成设置记录首次完成时间。保存进度保持浏览访问、日志、导入记录和采集能力独立。只读角色可以浏览说明，修改进度需要完整登录及当前网站的管理权限。保存前在事务内重新核验权限。

保存响应到达时，仅在用户仍停留于发起保存的导航上下文时自动进入下一步。用户切换步骤、接入方式、网站或页面后，原请求的结果继续保存，页面保持用户的新位置。

选择日志方式时，立即更新当前流程的草稿和地址，使路由提交前后的步骤链接都携带本次选择。真实导航变更后，草稿由新地址接管。完成、汇总与检查页读取后台已保存的方式；历史地址中的方式参数保持流程草稿的用途。

检查使用网站创建至今的页面访问和有效日志。示例网站的浏览访问与日志均标明数据性质，示例数据保持中性状态，并提示它们无法证明实际脚本或采集服务运行。读取失败、尚无数据、检查延后和实例未支持分别展示。

完整登录且有当前网站读取权限时，同一接入接口额外返回最近 30 分钟的浏览身份观测。观测使用具有会话关联及原始采集判定的公开浏览 PV，包含旧版覆盖来源，按接收时间计算；缺少观察接收时间时沿用原始采集判定的接收时间，事件业务时间保持独立。分母与正式统计资格分别说明。观测只返回汇总计数、时间、有限状态和原因，不包含 IP、完整 User-Agent 或访客明细。其他原有身份保持既有字段与权限边界，并省略新增观测。

身份观测在独立只读事务中核验当前权限，连接获取与事务共用 2 秒预算。诊断暂不可用时保留原设置、浏览及日志状态，覆盖率显示未知；权限撤销后拒绝读取。零样本、缺少身份资格证据、已证实不可用与部分可用分别呈现。少于 20 条样本仅提示样本不足；延后检查保留原标记。示例数据与未支持数据库路径单独说明。可信请求头配置、实际收到的身份样本、代理覆盖与源站限制各自保留核验含义。

系统支持 JS、手动日志导入、服务器采集及 Cloudflare 授权。自动入口根据实际运行配置展示可用性，缺少公网地址、签名安装资产、队列、处理进程或 OAuth 配置时，提示具体原因并禁用生成按钮。连接、真实接收和处理分别显示；平台运行与安全约束见 [自动日志接入](automatic-logs.md)。

网站设置的“基本设置 → 数据展示”提供按网站保存的“AI 蜘蛛数据展示”开关，默认开启。关闭后，AI 抓取导航和相关报表入口显示关闭状态，总览改用访客数、浏览量、跳出率与平均访问时长，并隐藏蜘蛛图表、抓取表格字段和 GEO 抓取发现。当前报表导出与公开分享遵循同一展示选择。AI 搜索带来的真人访问继续计入访客来源。

日志接入与完成页提供可选的访客统计引导，总览在尚未接入真实日志时提供轻量提醒。有效手动导入或已激活的自动来源可作为接入依据，示例手动日志不证明真实接入。跳过检查、完成设置、收到新日志均不会自动改变展示选择。关闭展示保留历史数据、日志采集、规则和安装配置；重新开启后可以查看既有记录。保存设置在当前网站的写入事务中执行，并更新报表缓存版本。
