# 导航与页面层级

猎看统计按资源范围组织页面。全局管理在顶部依次提供快速发起，以“数据管理”组织网站管理、数据看板和追踪管理，以“协作管理”组织分享管理和团队管理。团队管理后提供帮助中心，底部提供 AI能力分类和AI配置器，共八个入口。分类使用与网站导航一致的静态标题，各入口常展开。选择网站后，侧栏切换为流量总览及 AI 抓取分析、访客与来源、内容与转化、实时监测四个常展开分类，共 14 个入口。

数据总览（原工作台）页面已于 2026-10-08 下线：默认落地页与历史 `/dashboard`、`/liekan` 地址统一指向网站管理。网站管理列表提供今日/昨日/预计今日的访问次数、访客数、跳出率与 AI访问次数，整行可点击进入网站统计。

帮助中心入口统一放在全局管理侧栏。

## 页面范围

| 上下文 | 主要内容 | 归属规则 |
| --- | --- | --- |
| 全局管理 | 网站、看板、团队、链接、像素和分享列表 | 列表默认个人空间，可切换团队；网站列表可查看全部可访问网站 |
| 当前网站 | GEO、访客、事件、转化及深度分析 | 必须明确网站，页头显示紧凑网站选择；域名与所属空间位于选择面板 |
| 个人账户 | 资料、安全、API 密钥和偏好 | 位于侧栏底部，与网站选择独立 |
| 系统管理 | 所有用户、网站、团队及系统安全 | 系统管理员的独立管理上下文，保留实际后端权限校验 |
| 身份流程 | 登录、双重验证和恢复码 | 使用独立流程页面 |
| 公开分享 | 已授权的统计内容 | 使用分享资源与权限，独立于登录账户的侧栏 |

创建、编辑、安装验证、详情和播放器通过所属页面进入。全局管理入口直接进入对应列表，详情和编辑页高亮所属入口。网站分析分类为静态文字，各入口常展开并带图标。合并视图通过页面 Tab 切换，原有地址保持可用；详情和编辑高亮所属入口与 Tab。页头仅显示标题，日期与空间操作保留。

## 常用操作

网站页面共用顶部工具栏：左侧为返回网站列表与网站切换，右侧为日期及当前页面操作，标题位于工具栏下方。桌面工具栏高度为 60px，控件高度统一为 36px；桌面操作与网站切换、语言选择保持一行；窄屏的操作栏保持单行并支持横向滚动，触控高度为 44px。GEO 与扩展统计页复用同一组件，网站选择的样式由共享导航维护。顶部移除蜘蛛身份范围筛选，抓取总览的「管理蜘蛛」沿用当前网站的管理流程。右上角统一保留一个「robots 管理」入口，属于当前私有网站，点击后展示线上文件概览、公开地址、已授权服务器路径和当前统计范围内的建议，并可进入编辑与发布。切换网站会关闭原面板；全局管理、账户和公开分享页保持各自上下文。

- 追踪管理通过“链接追踪”“图片追踪”两个 Tab 管理短链点击和追踪图片请求。两种资源保留独立列表、创建、编辑与详情地址，统一高亮追踪管理入口。Tab 切换保留所属空间和日期，清除另一种资源的标识、搜索和分页条件。图片请求次数受代理、缓存和重复请求影响。
- 网站管理进入网站统计或网站设置。网站设置包含基本信息、安装接入、采集设置、分享设置和危险操作五个分区。
- 当前网站内容顶部可切换网站、返回网站列表；名称按钮展开搜索与网站列表。切换网站保留日期，清除原网站的记录标识、分群和筛选；详情回到新网站的列表，未保存的编辑会提示。
- 新建网站、看板、链接和像素可选择有创建权限的所属空间；编辑保留资源真实归属。创建表单等待空间与来源读取成功，读取失败提供重试。系统管理员访问非成员团队时，通过现有团队接口核验元数据和来源。
- 看板、链接和像素通过自身资源标识获取来源和归属，网站选择对这些独立资源没有影响。工作台保留已保存的个人与团队来源。
- “分享当前网站”只展示和创建当前网站的分享链接。全局分享列表按所属空间展示网站、看板、链接和像素分享。
- 分析工具沿用原模块，从详情进入时返回对应列表。旅程返回保留类型、步数和起终点；跨网站继续清除网站条件。默认日期与滚动日志窗口随导航保留，当前页面按读取时点固定窗口，主动刷新或重进后更新；明确选择历史日期时保留所选范围。
- 搜索、分页和排序条件写入列表地址，便于刷新、分享地址和返回列表。网站分析之间保留适用条件；进入暂不支持该条件的 GEO 页面时清除条件并显示提示。

## 日期、状态与文案

统计页显示实际期间与账户偏好的时区，默认 `Asia/Shanghai`。实时访客、日志更新和安装验证各自说明窗口。浏览接入成功以收到页面访问为依据；日志、内容目录和录制配置分别检查。真实零值、尚未接入、当前期间无数据、读取失败和实例暂不支持保持独立。

界面统一使用“访问记录”“访问详情”“行为人群”“UTM 活动”“API 密钥”“网站设置”。动作写明对象，例如“保存目标”“创建分享链接”“删除看板”。身份原因无法进一步确定的 401 显示“需要重新登录”，403 显示“没有访问权限”。

网站公开分享的总览按“访客概览、AI 与来源、地域分布”组织完整报告，复用原有八张图表、浏览器与操作系统排行及城市明细。默认最近 30 天、`Asia/Shanghai` 时区，日期与快捷范围统一更新整份报告。网站汇总报告仅支持日期筛选，其他分享页面保留已有筛选能力。专用 `shared-report` 接口实时校验网站分享与总览权限，转化结果另按目标权限控制；返回汇总字段，保留示例数据标识，排除日志明细、访客 IP、管理配置与内部游标。原有私有分析接口继续要求完整登录。

## 维护与验收

页面归属定义在 `src/lib/liekan/contracts/navigation.ts`，侧栏由 `src/components/liekan/Navigation.tsx` 统一渲染。路由适配集中在 `features/routes.ts`，上游请求通过 `src/lib/liekan/upstream`。新增功能先确定页面范围、上级页面、资源归属和状态，再接入导航。

网站地址统一携带短站点编号（`/websites/101/...`，按创建顺序从 101 分配），原 UUID 地址继续可用；站点切换、列表、页头与设置入口使用 `websiteHandle()` 生成编号链接，安装代码、分享地址和采集接口仍使用网站 UUID。

打开旧 UUID 页面时，共享导航在读取当前用户有权访问的网站信息后替换为编号地址，保留日期、筛选和锚点。蜘蛛归因与访问控制通过匹配当前路由的网站信息解析 UUID，再请求相应接口。

2026-10-04 确认的原型已经统一接入后台。五组合并视图如下：

| 入口 | Tab |
| --- | --- |
| 来源渠道 | 来源渠道、UTM 活动 |
| 页面事件 | 页面与内容、事件分析、热力图、页面性能 |
| 访问记录 | 访问记录、会话回放 |
| 转化分析 | 转化概览、目标、漏斗、转化归因、收入 |
| 人群分析 | 行为人群、留存分析、访问旅程、维度拆分、对比分析 |

已保存分群位于人群分析工具按钮，支持查看条件和应用；管理与编辑继续使用原页面。Tab 使用独立页面地址，刷新、前进和后退按地址恢复。分析来源由 `analysisSourcePage` 判断，菜单家族由 `activeNavigationPage` 判断；合并菜单不改变查询归属。日期跨视图保留，GEO 页面继续清除其不支持的筛选。

侧栏文字 13.5px，桌面按钮高度 34px、行距 36px，移动端按钮至少 40px。顶部站点行高 56px，返回入口使用带文字提示的箭头按钮。账户、项目信息和当前网站设置合为底部一行；全局与系统管理保留适用的管理入口。身份与公开分享流程保持各自独立上下文。标准记录在 `navigation-ui.json` 的 `websiteLayout` 与 `analysisTabs`。

原型 HTML 和指纹保持冻结。获批的导航、页头和文案变化使用 `config/liekan/navigation-ui.json` 独立验收；原主体图表、表格字段、面板和 VI 检查继续运行。响应式验证使用隔离浏览器，检查菜单数量、选中项、箭头留白、键盘操作、抽屉和页面溢出。完整验证和容器恢复流程见 [本地部署](local-deployment.md) 与 [上游更新](upstream-upgrade.md)。

## AI 页面

快速发起与AI配置器属于全局页面，不继承网站分析筛选或通用资源标识。快速发起必须明确选择网站，并依据目录中网站的真实所属空间读取连接与权限。AI配置器可选择目录提供的个人或团队空间。网站分析、账户和系统管理继续使用原上下文。

AI 页面地址仅携带经过格式校验的网站、对话与任务标识。问题、回答和密钥不写入地址或浏览器存储。刷新恢复只回查原任务；重新发起会创建新调用。历史依据展示生成时保存的快照，当前统计页面可能随新数据变化。实例关闭 AI 能力时，两个入口继续提供状态说明。

## 功能弹窗

团队详情的成员卡片右上角提供“新建用户”，仅系统管理员的完整登录会话可以创建账户。弹窗设置用户名、初始密码、确认密码及团队角色，账户以普通用户身份加入当前团队，默认团队只读。团队成员可创建、修改、删除团队网站；团队只读限制当前团队，普通账户的个人空间保留创建能力。系统管理员和全局只读角色继续由系统用户管理配置。

账户和成员关系在同一事务创建。新接口拒绝 API 密钥、公开分享和双重验证临时身份；用户名统一小写，密码不超过 72 个 UTF-8 字节。添加已有成员与角色编辑按服务端实时权限检查当前成员级别和将要授予的角色；团队管理员只能授予较低级角色，团队所有者身份保持独立。密码、哈希与数据库调试参数不进入日志。

创建成功后保留账户及角色结果，按服务端的加入时间和成员 ID 顺序定位新成员所在页。列表读取失败提供重新读取，创建结果继续保留。响应丢失时通过本次固定账户 ID 只读核对；未查到记录仍显示结果未确认，只允许继续核对或关闭，避免把创建后已被删除的账户重新建回。未知结果不保留初始密码供再次提交。用户名重名保留可修改表单；账户 ID 冲突先核对本次结果。创建请求 30 秒到期，核对请求 10 秒到期，到期中止浏览器等待并保留结果未确认状态。已存在账户的密码及成员关系不会在核对时被修改。关闭弹窗不撤销服务端操作，离页及身份变化丢弃迟到界面回调。规则见 `config/liekan/team-user-ui.json`。

管理、编辑、选择、确认与只读明细统一使用 `LiekanDialog`。弹窗以浏览器视口为中心，普通场景上限 920px，日志、规则、导出明细、分群和看板组件上限 1120px。标题与操作区固定，正文独立滚动；桌面边距 32px，窄屏边距 16px。获批场景与几何规则见 `config/liekan/dialog-ui.json`，原始参考与主体视觉门禁继续保留。

操作区通过 `DialogActions` 放入统一底部；提交按钮使用原生 `form` 关联正文表单，保留浏览器字段校验。关闭按钮、Esc、遮罩和取消共用关闭入口；有未保存内容时在同一弹窗中显示放弃确认。提交中是否允许关闭继续由功能的请求生命周期决定，一次性 API 密钥关闭后清除，迟到响应继续丢弃。打开时焦点位于安全位置，关闭后恢复到仍存在的触发元素。

所属网站、团队和资源来自当前页面已授权的上下文。网站设置、AI 爬虫与日志页的识别规则入口读写同一份配置；界面名称统一为“蜘蛛识别规则”，内部动作标识保持稳定。锚定菜单、网站搜索列表及移动端左侧导航沿用对应容器。


## AI 快速发起

快速发起首页通过输入框底部的选择器明确网站；日期和模型与网站选择并列，发送按钮位于右侧。首页下方提供抓取、来源、地域地图、页面、转化和日志入口，以及四种示例提问。示例问题只填入输入框，用户发送后才发起分析。网站快捷入口携带当前网站与有效 `date` 范围，日志入口使用 `live=0` 保持所选期间。

首页样式以 `design/reference/ai-chat-home-v3/agent.html` 为准，使用白色画布、860px 内容区及原型的常用功能与工具指引布局。输入框聚焦时只有一层中性边界，网站和模型选择通过已有控件边界标记键盘焦点，不额外描边。Enter 发送，Shift+Enter 换行，输入法确认文字时不发送。首页历史列表使用有背景和边界的锚定面板，Esc 关闭并将焦点恢复到入口。原型的静态示例答案仅用于视觉参考。

当前空间缺少可用模型时，页面显示一句配置提示；发送会打开居中配置弹窗。弹窗复用 AI配置器的表单与测试流程，保留当前问题。保存后由用户发起连接测试，只有本次测试成功、连接与配置版本一致、服务端验证状态有效时自动选用。关闭弹窗、切换对话或选择本地接入指引会使迟到的启用回调失效。配置密钥继续只写入服务端，不保存在浏览器。视觉与交互规则记录在 `config/liekan/ai-ui.json` 的 `chatHome`，原始参考指纹保留。

普通读取遵循 `docs/analytics-cache.md` 的手动规则。导航悬停、键盘聚焦与内部重挂载无预读；实际离开后返回产生新读取轮次。短编号和 UUID 地址归一化共用当前轮次，主题和语言变化保持统计快照。

删除当前网站、团队、用户、看板、链接或追踪图片，以及退出当前团队，成功后通过 `useAction` 的 `navigateTo` 替换当前历史并返回所属列表。完成路径先封存旧读取代次，再取消当前身份相关的在途读取并标记缓存失效；身份预检的迟到回调无法恢复旧代次，离页操作保持锁定直到卸载。列表进入时加载最新内容，成功提示说明实际操作结果。清空数据、转移网站及其他保留当前资源的操作完成一次页面刷新。操作失败保留确认内容供重试。重新打开已删除网站的旧地址时，空资源响应显示已删除说明与返回列表入口。

网站删除成功后，在网站列表中央使用共享宽屏弹窗展示网站名称、域名、删除范围和后续说明。弹窗由用户通过“知道了”、关闭按钮或 Escape 关闭，列表读取失败仍保留删除结果。结果只属于当前登录身份，离开网站管理流程后清除，重新加载页面不会重复展示。

浏览器缓存历史返回通过可信的 `pagehide` 离开和 `pageshow` 恢复配对确定新的访问；当前页面冻结恢复保持本轮结果。事件含义见 [MDN pagehide](https://developer.mozilla.org/en-US/docs/Web/API/Window/pagehide_event) 和 [pageshow](https://developer.mozilla.org/en-US/docs/Web/API/Window/pageshow_event)。公开分享切换分析分区属于主动读取，授权续期保持当前分区快照。


来源分析的标签顺序为“来源渠道 / 搜索引擎 / 来源关键词 / UTM 活动”。来源关键词地址为 `/websites/[websiteId]/geo/human/keywords`，属于网站私有分析，侧栏仍高亮来源渠道。切换网站或分析标签时清除关键词引擎、依据、状态、排序、页码和统计快照，保留日期范围。

搜索引擎地址为 `/websites/[websiteId]/geo/human/search-engines`，沿用来源渠道所属网站与日期范围；标签切换清除平台明细的类型筛选和排序。

升级专项的历史数据修复页面位于 `/settings/data-repair`，属于全局网站管理上下文；入口来自网站管理、全局网站管理和网站设置。站点预选只传 `websiteId`，不继承分析筛选条件。详见 [历史数据升级修复](history-repair.md)。

侧栏底部四宫格为“关于 GEOInflow”按钮，在全局、网站和系统管理页面打开共享 1120px 居中弹窗。弹窗展示联合开源方、项目发起人和贡献者待接入状态；联合开源方名称链接到带 `?GEOInflow` 参数的官方网站。关闭弹窗返回原页面及触发按钮。网站顶部返回列表入口继续按网站归属携带空间。移动端弹窗打开时，由弹窗管理焦点和 Escape，侧栏保留展开状态。
