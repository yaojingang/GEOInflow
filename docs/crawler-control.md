# AI 蜘蛛归因、风险与访问控制

入口在网站的「AI 蜘蛛」页面和「数据接入」的蜘蛛分析按钮。面板沿用现有网站上下文，包含归因、风险、公开访问检查和访问策略。账户页的「蜘蛛规则交接记录」保留断开、转移和删除后的规则线索。

## 归因与风险口径

蜘蛛按具体 UA 与用途区分，训练、搜索、用户触发和传统搜索分别呈现。UA 声明、官方 IP 段匹配与范围不匹配分别统计。IP 段匹配仅代表该请求与已知范围一致。自定义 UA 规则保留原有识别能力，无法明确映射到目录的记录归入未映射项。Google-Extended 作为 robots 用途控制项呈现，不产生独立 HTTP 蜘蛛统计。

每个平台的浏览器引荐访问与目标转化独立汇总，同平台多个蜘蛛共享一个平台指标。引荐根据既有入口分类和 UTM 优先级统计；这些数据无法证明某次抓取直接带来了某次转化。页面路径保留原编码、大小写和尾斜杠，人类可读路径仅供查看。页面及落地页列表最多 1000 项，超限明确提示。

详情查询最多覆盖 90 天，结果缓存 30 秒；首次读取大量数据需要等待聚合。单条查询最长 30 秒，整体快照事务最长 60 秒，超时提示缩小时间范围。浏览器归因使用访问首次入口，保留时间窗之前的入口字段；一次访问只计一次转化，同一事件命中多个目标时仍只计一次目标事件。

请求总量、2xx、3xx、304、4xx、5xx、HEAD 和成功 GET 分开计数。成功页面覆盖只统计目录中取得 2xx 的 GET。风险涵盖访问受阻、源站错误、抓取突增、覆盖下降、关键页面访问预期、身份范围异常及敏感路径访问。分析按事件时间使用完整 UTC 小时，最近 15 分钟保留给迟到数据；近 48 小时会重算并修正已记录的发生窗口。发现有稳定标识、证据、置信度、首次和最近时间、发生窗口数，可忽略并保留状态；连续两个完整良好窗口才判定恢复。

访问异常、覆盖下降和引荐减少只能形成风险线索。界面不会据此认定搜索引擎降权、索引减少或 AI 推荐排名变化。确认这些结果需要额外的搜索平台与可见性数据。来源中断、未接入、规则口径变化与真实零请求分别显示；缺少可靠比较条件时保留观察状态。

## 来源质量

新版服务器采集器与服务端协商覆盖能力，提交已持久确认的文件代次、游标、起止批次及事件时间范围。服务端验证当前采集代次、来源生效区间、全部相关批次处理完成、无拒绝记录、无待处理积压、分类口径一致后，记录采集器观察到的连续文件范围。已证实覆盖的零请求小时可以显示完整状态。

该声明的边界是采集器实际观察到的日志文件。网站日志配置遗漏、上游缓冲未落盘、隐藏抓取身份等仍需运营核对。轮转或截断缺口与格式错误记为部分覆盖，确认缺口已记录且缓冲清空后开始新的覆盖段。旧采集器继续兼容接入，缺少覆盖声明的时段显示口径未知。手动导入与 Cloudflare Logpush 当前也保留未知覆盖口径，避免把日志未到达解释为蜘蛛停止访问。

## 公开访问检查与导出

公开检查先验证当前网站的 DNS TXT 挑战，挑战值只在生成时返回，数据库保留哈希。检查只请求同域名的 HTTPS 443，逐跳重新解析并排除私网地址，限制跳转、时间和返回内容。使用标记为 self_check 的身份，统计排除本系统检查流量。检查代表当前公开响应，不能代替真实蜘蛛的访问证据。

robots 导出先解析已有内容；无法安全合并时提供片段与原因。robots 的遵守取决于访问方。Nginx 可导出屏蔽或限速配置，分别标明 http 与 server 上下文，并提供部署、语法检查和恢复说明。导出内容由网站维护者部署；猎看本版不远程修改 Nginx。

robots 的线上读取、定时监控、服务器授权发布和回滚见 [robots.txt 管理](robots-management.md)。

## Cloudflare 操作流程

网站流量需要经过 Cloudflare 代理。控制连接使用独立、仅限当前 Zone 的 Token，与日志采集授权分开。Token 使用 `LIEKAN_LOG_CREDENTIALS_KEY` 加密，浏览器只在输入时短暂持有，查询返回掩码。连接读取 Zone 和规则入口；实际套餐可用性、Token 写权限及边缘真实命中需要在用户测试 Zone 验收。

团队成员可保存观察草稿；远端控制要求网站所有者、团队负责人或平台管理员。新接口仅接受完整私有登录会话。公开分享、API key 和未完成二次验证的身份无法调用。

操作顺序为保存草稿、读取远端生成差异、核对影响、确认、后台执行、远端回读。预览十分钟有效，绑定网站归属、策略版本、目录口径、凭据及远端摘要。确认使用幂等操作 ID。Worker 写入前再次校验权限和上下文，并按 Zone 串行执行。仅修改本平台登记的单条规则；人工改动规则字段、相同 ref 身份冲突或配额不足时停止操作。

本版支持观察、屏蔽、停用、恢复明确版本及移除本平台规则。规则匹配声明的 UA 和所选原编码路径。全站或搜索蜘蛛屏蔽的影响在预览中显式展示，历史匹配量带有估算与缺失状态。观察策略只在猎看内生效。

配置回读一致、请求匹配本规则、本规则实际终止请求分别验证。Cloudflare 日志缺少终止动作及规则 ID 时，界面显示无法归因。已知配置切换附近的五分钟不用于版本预期判断。预期内屏蔽单独呈现执行结果。

## 中断、接管与恢复

网络中断导致结果未知时，同 Zone 暂停后续写入，先只读核对远端；系统不会自动重复创建规则。远端与操作前状态完全一致时，需明确确认未应用后结束该任务。更换 Token 可用当前同 Zone 凭据核对旧操作，读取凭据不会自动取得原规则写权限。

归属变化后的原规则需要单独「预览接管原规则」并确认。接管只读核对原域名、Zone、ref、规则 ID 和完整配置摘要，再更新本地登记；后续发布、停用和清理仍须独立预览确认。域名改变后保留原 Zone 交接线索。网站删除后的未知任务可在账户交接记录中，用当前同域名同 Zone 连接明确只读核对；调用者同时需要原空间管理权与当前网站控制权。

断开默认立即销毁本地凭据并保留远端规则，用户应在 Cloudflare 撤销不用的 Token。选择清理模式需明确确认，清理凭据最长保留七天，完成后立即销毁。重置分析数据保留控制策略与远端配置；转移、域名变化和删除冻结控制并撤销本地活跃凭据。

恢复数据库时先停止应用和 worker，恢复后、启动服务前运行 `node dist/liekan-worker.mjs --pause-crawler-control`。该命令暂停控制、取消旧排队任务并将旧运行任务标为待回读；数据库备份本身不具备识别恢复操作的能力。管理员核对当前连接及未知操作后恢复；恢复时全实例旧排队任务取消、旧预览到期，各网站须重新预览。已经发出的远端请求仅记录实际结果。加密密钥轮换沿用 `node dist/liekan-worker.mjs --rekey`，包含访问控制连接。分析证据保留 90 天，操作交接保留 180 天；当前生效版本的审计记录继续保留，已删除网站交接记录在 180 天后清理；尚未明确的远端操作持续保留，平台管理员可用当前同域名同 Zone 连接只读核对。

## 部署与验收

部署使用 Node 22、PostgreSQL、独立 worker 和固定队列初始化。执行既有上游迁移及 `pnpm liekan:migrate`，再运行 `pnpm liekan:queue-bootstrap`，重启应用和 worker。迁移 015 为增量表，已有 tracker、SDK 和上游表结构保持兼容。现有签名采集器需通过受信任构建与升级流程更新后才能提交覆盖声明。

HTTP 代理需保留浏览器请求的 Host；HTTPS 终止代理设置单一的 `X-Forwarded-Proto: https`，并覆盖客户端传入的该头。写接口据此校验浏览器 Origin，Docker 内部地址用于服务监听。`X-Forwarded-Host` 不参与来源授权。

自动化测试覆盖权限、来源口径、风险恢复、robots 合并、Nginx 实际请求、策略幂等、人工规则冲突、未知结果恢复、凭据替换与接管。真实 Cloudflare 测试 Zone 验收包括 Token 最小权限、套餐和配额、代理状态、预览确认、配置回读、真实日志命中、停用及恢复。完成这些检查前，供应商真实写入与边缘效果保留待验收状态。

后续能力包括 Search Console、Cloudflare 限速、自动到期和 Nginx 远程执行，分别设计和授权。

统计证据、采集对账、观察保留期与风险工作流详见 [流量证据与统计口径](traffic-evidence.md)。
