# 官方默认示例：猎看官网

“猎看官网（示例数据）”是 GEOInflow 随系统分发的官方展示网站，域名为 `www.liekan.com`，网站 UUID 为 `b880cb21-e65a-4fdf-9c0e-3da5aed4e0fa`。数据库设置 `is_demo=true`，界面与导出保留示例标识。示例采用合成访问、内容和爬虫场景，方便部署后体验各个统计页面。

## 随版本分发

每次推送源码、制作发布归档或构建 Docker 镜像，均须携带以下三个文件：

- `scripts/liekan-demo-data/official.ndjson.gz`：完整、脱敏的展示数据。
- `scripts/liekan-demo-data/catalog.json`：示例使用的爬虫目录。
- `scripts/liekan-demo-data/manifest.json`：格式版本、逐类数量、时间基准和两个文件的 SHA-256。

数据包与源码一起下载，无需连接开发者的数据库。构建和 CI 运行 `pnpm liekan:check-demo`，校验文件摘要、逐条引用、隐私字段、爬虫目录与源码的一致性、近期日期及页面功能覆盖。更新官方示例后须同时更新整个数据包，并在独立空库完成完整导入验收。

包内同时包含流量质量、设备环境、地域、属性、导入批次、暂停的合成日志源、规则、区间与部分覆盖证据。统计快照与汇总结果由实例后台根据已导入记录统一生成，实例权限、缓存身份和计算租约由本地系统管理。

首次导入将最新访问设置为导入开始时间前 5 分钟，其余记录同步平移，保留时间间隔和关联关系。近期各页面具备完整示例场景，原有更早示例记录继续保留。重复启动不会平移已有数据。

## 自动初始化与删除

Docker 启动依次完成迁移、自动初始化示例、后台队列准备和页面服务启动。首次导入使用已有的有效管理员作为网站拥有者，保持账号、密码和角色完整。整个导入在一个事务内完成，并用数据库锁串行化并发启动；错误会回滚本次写入。批量导入期间使用现有统计生命周期屏障，完成后一次性标记后台重建。

用户可通过网站设置删除示例网站或清空其数据。后续重启、升级、重复部署及手动初始化都会尊重删除状态，清空后的示例保持为空。系统通过软删除状态和持久统计版本记录保留这一选择，请保留这些记录。

已有数据返回 `existing`；已删除返回 `deleted`；已清空返回 `cleared`。改名、修改域名或 UUID 冲突时，自动启动返回 `customized` 并保留现有资源，手动导入提示冲突。管理员均已删除时，自动启动跳过初始化，账号保持删除状态。

已有安装包含其他网站且从未创建官方示例时，自动启动返回 `existing-installation`，保留当前业务资源和启动耗时。需要补充示例时，由维护者显式执行 `pnpm liekan:seed-demo`。

导入保留现有全局爬虫目录的发布权。相同内容或所需身份、IP 范围源语义完全兼容时，示例绑定已有发布版本。自定义目录与示例不兼容时返回 `incompatible-catalog`，保留后续导入机会，管理员可先完成目录配置。默认全新部署自动建立源码内置目录。ClickHouse 和云模式跳过此 PostgreSQL 示例初始化。

## 手动开发与维护

完整示例包含约137万条记录，首次初始化耗时取决于数据库资源和磁盘。应用在导入事务提交后开始提供服务，部署为这一过程保留30分钟启动等待。已有数据、自定义、清空或删除状态直接复用，重复启动会跳过导入。超过等待预算时检查初始化日志和资源，保留原有配置与数据。

完成数据库迁移后，手动开发可执行：

```sh
pnpm liekan:seed-demo
```

维护者更新隔离的官方合成示例后，显式使用私有数据库配置导出候选包：

```sh
pnpm liekan:export-demo
```

导出结果包含 `.local/demo-exports/` 下的独立候选目录，保留仓库内现有数据包。确认候选的脱敏字段、数量、时间范围及校验值后，将其中的压缩数据、目录和清单作为同一组更新到 `scripts/liekan-demo-data/`，再执行校验和完整隔离导入：

```sh
pnpm liekan:check-demo
LIEKAN_DEMO_TEST_DATABASE_URL='本机独立测试库连接' node tests/liekan/default-demo.integration.mjs
```

导出仅允许固定 UUID、固定名称与域名且设置 `is_demo=true` 的网站。维护者应先核对示例内容；正式业务数据保持在各自网站中。支持 `DATABASE_URL` 的独立 schema 参数，导出采用只读一致性快照。

## 隐私与统计语义

数据包用顺序编号关联记录，导入后生成 UUID 和实例密钥绑定的哈希。账号、密码、访问令牌、原始访客 IP、原 IP 哈希、自定义身份、广告点击标识、连接凭据和 AI 对话均排除。属性使用预设合成值；仅保留预设的合成搜索词。回放限定为固定示例页面和鼠标、滚动动作，拒绝私有 DOM、输入内容及带凭据的地址。

公开厂商 IP 范围归档用于重现示例核验场景，保持原归档时间和来源，导入不改变活动范围指针。官方合成爬虫规则随包按内置目录重新生成；身份与测量均带合成标识，覆盖状态保持部分观测。历史缺失的流量判定和测量输入继续保持未知。示例分数只用于功能展示。

单元测试覆盖文件、引用、时间平移、隐私、冲突及删除保护；独立数据库验收检查完整自动导入、各类数量、PV/转化/性能、可解码回放、属性摘要、管理员保持、重复启动、目录权属及软删除、清空、硬删除状态。私有数据库备份与本地验收输出保存在 Git 忽略目录。
