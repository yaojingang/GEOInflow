# AI配置器与快速发起

AI 功能使用用户配置的供应商 API。连接测试和分析按供应商规则计费。后台统计、登录、tracker 和既有统计数据继续使用原契约；AI 默认停用。升级保留现有网站接入步骤、检查延后选项和完成状态。

## 启用

1. 升级前备份数据库，并保存当前版本及迁移账本。
2. 先应用上游迁移，再执行 `pnpm liekan:migrate`。AI 使用独立增量表，保留既有统计表。升级保留已用迁移的原文件名和校验值，完整清单见 `config/liekan/migrations.json`；相同数字前缀由完整文件名区分。
3. 在部署环境中设置 `LIEKAN_AI_ENABLED=true` 和独立的 `LIEKAN_AI_ENCRYPTION_KEY`。后者为随机 32 字节密钥，以 64 位十六进制保存。可使用 `openssl rand -hex 32` 生成，写入权限为 0600 的配置文件，禁止提交到 Git。
4. 重启应用，在“AI配置器”选择所属空间，新建 API，选择模板并输入供应商 Key。Key 保存后只显示“已配置”。
5. 完成实时测试后，将启用的连接设为默认。在“快速发起”明确选择网站及统计日期，再提交问题。

AI 加密密钥与登录、2FA 密钥分别配置。配置缺失或格式无效时，AI 页面显示部署原因，既有统计功能继续运行。Compose 透传两个可选 AI 环境项。多实例共享同一个 PostgreSQL 主库及 AI 加密密钥。

## 模型模板

接入参数以 `src/lib/liekan/ai/templates.ts` 的核对基线为准。模板选择自动填入名称、协议、基础地址和模型；已保存的连接保留用户确认的参数。账号可用模型、Key 地域和费用需要在对应供应商控制台确认。

模板包括 OpenAI、Claude、Gemini、DeepSeek、千问、Kimi、MiniMax 和自定义兼容接口，各模板提供官方接入文档。地域只采用准确匹配的模板信息，其他连接显示未知；网站或服务站点信息不承诺数据驻留地域。自定义接口需要公网 HTTPS、443 端口及支持的文本 API 路径。私网代理、任意请求头和附加 URL 参数不在当前接入范围内。Claude 工作空间条件通过受限高级字段填写；千问默认北京地域，其他地域须使用匹配的地址和 Key。

连接能力分为文档声明、协议测试和当前 Key 实际验证。文本测试成功只证明本次文本请求有效。流式、结构化输出、工具和用量分别记录，未知值保留未知。列表读取不会发起收费请求。每个空间最多配置 20 个连接，只允许一个默认连接。网站与团队目录每页最多 100 项，使用“加载更多网站与空间”读取后续页；显式选择的网站会在当前权限范围内补查，并补齐其所属空间。切换配置空间会关闭表单及操作弹窗，清空尚未保存的 Key。

修改 Key、供应商、协议、地址、模型、工作空间或启停状态后，当前验证失效，需要重测。变更供应商、协议、工作空间或地址域名时需要重新输入 Key。表单使用版本检查，旧版本保存返回冲突；测试结果绑定配置版本和启动顺序。

## 数据、权限与输出

连接属于个人或团队空间，对话仅限创建者查看。分析绑定明确网站，连接必须与网站所属空间匹配。团队普通成员可使用团队连接，管理和测试需要团队管理权限。账户只读、团队只读、公共分享、账户 API Key 身份和未完成双重验证的身份不能发起收费 AI 请求。

当前实现提供网站摘要、爬虫变化、日志异常、AI 引荐、页面表现和目标转化六类有限事实。日期上限 90 天，前期为紧邻的等时长窗口；未来结束时间截断至实际取数时间，当日未完整及日志覆盖未知会明确说明。摘要读取共享一个数据库预处理通道，每个应用实例使用独立、最多一个连接的主库取数池；权限预检在同一独立池的短事务内完成，提交后再开启只读事实快照并复核权限；等待任务保留原统计连接池容量。数据库连接预算需为每个实例额外预留一个连接。同一实例内已开始的日志统计读取优先完成；新的 AI 取数在取得连接与后续语句前检查这一优先条件，持续繁忙时按期限返回超时。已执行的 SQL 保留原有执行方式，跨实例仍共享预处理通道。取得连接、等待统计读取、排队与查询合计最多 5 秒，以减少并发扫描对统计浏览的影响。每个维度最多 20 行，异常日志最多 20 条脱敏样本，保留总量、筛选方式和截断信息。未接入、范围内无数据、实际零值、估算和不支持分别呈现。ClickHouse 实例显示本地暂不支持指引。

外发数据经过明确字段投影和路径脱敏。标签中的 URL 查询或敏感路径与后续空白存在范围歧义时，整段标签脱敏。原始 IP、访客标识、完整 UA、查询参数、任意事件属性、录屏和目标原始条件不进入模型上下文。当前问题与有限历史问题在模型请求组装时同样经过敏感信息脱敏；本地原始消息保留现有权限和到期规则。自动规则无法识别所有商业秘密和个人资料，输入时仍应避免这些内容。首版不支持附件、外部搜索和模型执行操作。

模型输入总量上限 32 KiB，采用保守窗口预算，最多最近 6 轮完整历史，优先保留当前范围、来源状态和基础指标。未知模型采用 16,384 Token 的应用保守窗口，并显示限制来源。输出上限 32 KiB，分析生成最多 2048 Token，连接测试最多 512 Token。格式、依据编号和页面动作校验通过，并完成数据库提交后，才展示正式回答。生成预览标记为尚未校验。成功响应在预览发送和保存前检查当前 API Key，覆盖跨片段及 JSON 转义；检测到回显后终止任务并返回安全错误。

输入预算按实际选择的输出能力计算：已验证的结构化输出在协议字段中发送回答 Schema，其余连接在提示中发送 Schema，每次只计入一份，并保留协议字段余量。输入预算不足使用 `input_budget` 错误，传输或响应大小超限使用 `oversize` 错误。纯问候通过完整匹配返回本地引导，保留接入及提交权限核验，不读取统计、不外发、不占用每日模型次数；包含分析要求的问候继续准备统计。问候回答标明本地来源，数据分析及后续历史仅使用已保存的事实快照。

浏览器汇总在同一快照内一次扫描当前期与基期，保留统计页的 PV、访客与访问计数及毫秒边界；查询和排队继续共享五秒期限。可能原因的不确定性规则同时进入模型的 JSON Schema 与服务端校验，中文生成提示要求以“可能：”开头；未通过结构、纯文本或依据校验的回答继续拒绝。

预算裁剪先移除历史与日志样本，再裁剪 TopN 尾部；页面、目标、日志异常或爬虫问题优先保留对应主题明细。汇总计数、来源状态、脱敏后的问题及遗漏数量继续保留，所存快照反映实际发送的范围。

指标卡来自服务端事实。AI 与统计页共用有效日志视图，按来源生效区间处理手工导入与自动采集的重叠；自动来源已启用且尚无数据时显示空数据状态。回答区分观察、可能原因、建议和限制。依据打开生成时快照，后台入口展示当前统计，后续数据导入可能使两者不同。历史依据到期后不能用当前数据替换。自然语言与合法引用仍需结合业务判断。

## 运行与取消

测试总时限 45 秒，分析总时限 120 秒，首包和片段间隔上限 30 秒。模型请求不自动重试，不自动切换供应商。连接测试显示实际文本、用量与计时、受限状态码和请求编号；响应未提供编号时显示未知。非流式请求的首字耗时为不适用。

PostgreSQL 统一控制全局最多 3 个运行、每用户 1 个运行、每用户每分钟 10 次、每空间 UTC 每日 100 次。每日次数在接受时预留，仅确定未发出供应商请求的本地指引释放预留。运行租约为 10 秒，每 2 秒续约；进程退出后保留中断状态，用户主动重新发起。

明确选择本地指引时，请求携带 `localOnly=true`，不会解析默认连接或调用模型；同时指定模型连接会被拒绝。

同一请求 UUID、相同内容回查原任务，内容变化返回冲突。刷新或连接中断后按 UUID 或运行 ID 回查，不重新收费调用。关闭测试弹窗或停止生成发送取消。已经由供应商处理的请求仍可能产生费用。

网站重置、转移和删除在原操作事务内清理派生问答与依据，更新网站 AI 世代。用户及团队删除同时清理所属 Key 与私有内容。账户或团队角色的显式保存、成员移除，会在同一业务事务中终止已有运行；重复保存相同角色也会终止。已完成的私有历史按当前权限读取。最终保存再次核对权限、配置版本、数据世代和租约，旧任务不能恢复已清理的回答。最终提交同时检查实时租约、45/120 秒操作期限和中止信号；保存跨过期限时整笔事务回滚。取消后租约到期的回查状态、阶段和错误均保留“已取消”。

## 清理与维护

消息、事实快照和测试正文保存 90 天；运行及脱敏管理审计保存 180 天。到期内容立即从读取接口隐藏。持续对话中，创建超过 90 天的自动问题标题清为“网站分析”，新追问保留原资料的到期时间。请求结束后机会式清理，消息与依据先分批清理，到期对话的运行引用分批解除，运行元数据继续保留；父对话仅在无子内容、无运行记录引用及无有效租约时删除。删除、内容清空及引用解除共用单批 500 条预算；结果的 deleted、cleared、detached 分别统计三类操作。维护状态记录最后成功时间、待清理量及静态错误码。长期无请求的实例应定期运行下列维护命令。部署管理员负责维护调度，应用不新增后台队列。

```sh
pnpm liekan:ai:maintenance check
pnpm liekan:ai:maintenance cleanup
pnpm liekan:ai:maintenance cleanup --apply --database liekan
```

维护默认预览，写入需要 `--apply` 及准确数据库名。先核对命令返回的数据库、主机和数量。运行日志只包含脱敏状态，不记录 Key、问题或回答。

### 离线加密密钥轮换

1. 在全部应用实例停用 AI，取消现存任务，确认没有有效租约。停止实例或禁用 AI 接入后再维护，单个命令进程的环境值无法代表其他实例。
2. 备份数据库，并单独安全保存与备份匹配的旧加密密钥。
3. 旧、新密钥分别写入无符号链接、权限为 0600 的文件。禁止使用明文命令行参数，文件仅包含 64 位十六进制内容。
4. 先预览，再执行轮换。命令在单事务中验证旧密钥、重新加密所有 Key，并验证新密文；失败整体回滚。
5. 事务成功后，将全部实例配置改为新密钥，再启用 AI 并完成连接测试。中途部署失败时保持 AI 停用，完成切换或恢复匹配的备份与旧密钥。
6. 按组织密钥管理流程保存必要备份，并移除临时密钥文件。

```sh
pnpm liekan:ai:maintenance rotate-key --old-key-file /secure/old-ai-key --new-key-file /secure/new-ai-key
pnpm liekan:ai:maintenance rotate-key --old-key-file /secure/old-ai-key --new-key-file /secure/new-ai-key --apply --database liekan
```

### 恢复数据库副本

备份恢复后先保持 AI 停用。恢复副本使用匹配密钥进行受控完整恢复，或执行 AI 重置以清除对话、供应商密文与验证状态，随后重新录入 Key。原统计数据保留。

```sh
pnpm liekan:ai:maintenance restore-reset
pnpm liekan:ai:maintenance restore-reset --apply --database liekan
```

独立加密密钥丢失时，供应商 Key 无法从密文恢复。使用 AI 重置流程清除旧连接凭据并重新录入。

## 开发验证

使用 Node.js 22 和冻结锁文件。本地单独运行维护命令前执行 `pnpm build:ai:maintenance`；正式构建自动生成维护入口，Docker 镜像直接包含该产物，帮助命令无需连接数据库。`pnpm liekan:verify` 覆盖类型、单元测试、生成器一致性、原视觉参考、构建、Docker 迁移、恢复副本及 API 回归。新增 AI 事实与后端集成测试必须使用命名的独立验收数据库，不能指向现有统计数据库。

AI SDK 及三个供应商适配器使用 Apache-2.0，undici 使用 MIT；精确依赖版本锁定在包清单和锁文件，原 Umami MIT 版权保留。协议夹具用于验证参数、流解析、取消及错误处理；真实供应商联调需要用户在 AI配置器中录入自己的 Key，并核对供应商返回与实际账单。

## 日志读取兼容性

`liekan_effective_log` 是只读统计契约。增量迁移 013 将手动日志与自动日志的筛选拆成互斥分支，保留网站、来源和时间区间规则，以及原视图的列结构、权限和依赖。写入继续使用 `liekan_log`。历史迁移文件及校验值保持不变。
