# Liekan 统计口径

访客 PV、UV、会话、跳出与时长使用同一有身份依据的浏览事件子集。访客 UV 统计该子集内整个窗口的匿名浏览标识，仍可能包含未识别自动化；它无法直接证明真实人数。“浏览器特征”表示 UA 与普通浏览器相符。质量分类分别展示，分类 UV 可能重叠。部分覆盖时指标只描述已纳入子集，覆盖比例和未纳入数据可在流量质量中核查；缺失身份的历史事件保持未知。

所有统计按当前网站隔离，私有页面默认按账户保存的时区生成查询，初始时区为 `Asia/Shanghai`。主要日期入口为今天、7 天、30 天；全局日期作用于卡片和表格，趋势图可使用独立的 30 天、7 天或今天窗口。AI 占比展示结束日期所在月及此前 5 个自然月。今日指标按当前查询时区的自然日边界计算，并保留实际数据截止时间；新分享使用创建时保存的时区。旧链接中明确指定的 `date=24hour` 保留滚动窗口含义，详见 [日期与时区](date-ranges.md)。

| 字段 | 口径与限制 |
| --- | --- |
| 浏览 PV / UV / 会话 | 复用 Umami v3.4.1：PV 排除自定义事件和性能事件；UV 为匿名 session_id 去重，会话为 visit_id 去重。日/小时 PV 和 UV 按浏览事件发生时间分桶，跨桶访问可在多个桶出现；会话、跳出与时长按窗口内首个浏览时间分桶 |
| 跳出率 | 一次浏览且无自定义事件的会话 ÷ 浏览会话 |
| 平均访问时长 | 同次访问首末浏览的时间间隔 ÷ 会话；单次浏览时长无法充分观测 |
| 页面停留 | 同会话后续浏览的时间间隔，末次页面停留缺少结束证据，标识为估算 |
| AI 请求 | 服务器日志中具备 AI 统计资格的请求，沿用导入时保存的资格；缺少该字段的旧记录按原有训练、AI 搜索或用户触发类型兼容，保留状态码和请求方法 |
| 今日总请求 | 今日已接入服务器日志中的内容请求数，按路径末尾扩展名排除脚本、样式、图片、字体和媒体；完整日志、异常请求、有效导入行数保留原始请求 |
| AI 抓取覆盖率 | 所选范围被 AI 请求的目录内 URL ÷ 已导入目录 URL；分母未接入时显示待接入 |
| 反复抓取 | 所选范围内同 URL 达到 50 次 AI 请求 |
| AI / 浏览 比值 | AI 请求数 ÷ 浏览 PV，分母为零时无定义 |
| AI 搜索引荐 | 每次浏览访问的入口 PV 上，优先使用明确 UTM 来源/媒介，再使用 Referer；原始 UTM 与 Referer 随来源证据保留，缺少两类证据时无法完整追溯 |
| 目标转化次数 | 匹配目标条件的 event_id 次数，同一次访问重复触发目标分别计数；每个目标独立计数。今日转化、每日趋势按匹配事件的发生日期聚合，全站事件次数对多目标重叠的 event_id 去重 |
| 目标转化率 / 全站率 | 目标率为命中该目标且在窗口内有浏览 PV 的去重 (visit_id, session_id) ÷ 浏览会话；全站、来源、地域的转化率使用任一目标命中的去重浏览会话，重复事件与多目标命中同会话只计一次 |
| 漏斗 | 复用 Umami 保存的漏斗步骤、时间窗口和匿名访客算法，详情沿用原功能。已保存参数须通过上游参数校验；无效配置显示 unsupported 并提示检查目标配置 |
| 内容发布效果 | 元数据发布时间后完整 7 天的浏览 PV；AI 增量为发布后 7 天请求减去发布前 7 天请求。属于观察值，缺少日志完整性与因果证明 |
| 结构化评分 | 目录导入者提供的 0 到 100 分证据；Liekan 当前阶段不自动给网页评分 |
| 抓取完成率 | 普通请求日志无法证明正文接收完成，保留未提供状态 |
| 蜘蛛身份 | UA 分类与来源核验分别保存。官方范围按身份适用的归档快照核验；快照超过 7 天或与请求时间相距超过 7 天时保留未核验。范围未匹配保留单独状态，已支持的 DNS / 可信边缘证据按各自方法独立记录，详见 [爬虫识别](crawler-recognition.md) |
| robots / 白名单 | 保存策略草稿并下载文件，执行需要同步到源站/WAF；不会宣称已阻断请求 |

状态包括 available、empty、not_connected、estimated、unsupported。生产界面不使用演示值补齐缺失字段。独立演示站由 is_demo 标记，在界面显示示例数据。

卡片与表格的比率保留零分母边界：无浏览会话时，跳出率和来源占比无定义；已配置目标且没有 AI 引荐会话时，AI 引荐转化率无定义并标记 empty；页面从未作为入口时，其入口跳出率无定义。对应数值返回 null，已有分母且转化/跳出为零时返回真实的 0%。

图表百分比使用同一零分母规则：内容分类的 AI/人类占比、每日跳出率、月度 AI 占比、渠道转化率在分母为零时保留 null 数据点，ECharts 绘制为空缺；有分母且分子为零时为 0%。图表系列值的契约为 number 或 null，保持原型的系列、坐标轴、尺寸和交互结构。

日志输入上限每批 10 MiB，combined 最多 10000 行，JSON 最多 1000 条，每站点每分钟 5 次，一个站点同一时间仅有一个导入事务。失败行只保存行号和原因。IP 原值仅在解析内存中用于核验，入库保留 IPv4 /24、IPv6 /48 及 HMAC。URL 查询参数和 fragment 均不保存。重复导入使用文件摘要和请求指纹去重，完全相同请求的重复行保留批内次数；跨文件缺少唯一请求 ID 时存在去重边界，建议源站导出不重叠的日志批次。

今日总请求的排除后缀为 js、mjs、cjs、css、map、avif、webp、png、jpg、jpeg、gif、svg、ico、bmp、tif、tiff、woff、woff2、ttf、otf、eot、mp3、m4a、wav、ogg、mp4、webm、mov、avi，忽略大小写。HTML、PDF、JSON、XML、TXT 等内容文档保留；扩展名后仍有路径片段的 URL 保留。该规则属于扩展名分类，无法证明实际响应的 MIME 类型。

入口字段按 created_at、event_id 的稳定顺序，从每个 (visit_id, session_id) 已存储的首个浏览 PV 同时取值（可早于统计窗口）；后续页面新增 UTM 保持入口归因。平台 UTM 来源仅接受明确别名（ChatGPT/OpenAI、Perplexity、Claude、Gemini、Copilot、豆包 doubao、Kimi、文心 yiyan、DeepSeek，以及 Google、Bing、Baidu、Sogou、360/so、DuckDuckGo、Yahoo）或配置在适配器中的平台域名及其子域名，统一到相应平台域名。email、e-mail、newsletter、sms、social、paid_social、paid-social、display、affiliate、push、banner 媒介优先归入其他引荐；未知 UTM 来源或只有媒介的记录保留原值并归入其他引荐。只有 campaign 时，保留 campaign 证据并使用 Referer；所有来源证据均空时为直接访问。当前、前期、每日和渠道转化共享同一归因规则；sourceEvidence 保留原始 UTM/Referer 的分组证据，原型 UI 列保持原有结构。

跨午夜访问的今日目标事件按事件时间计入今日次数，即使该日没有新 PV。转化率的分母与转化浏览会话采用同一统计窗口，窗口内仅有自定义事件的访问计入次数并不进入该窗口的浏览会话转化率。浏览会话分母为零时，目标率和全站率显示无定义，返回 null 与 empty 状态，目标事件次数仍可用。入口日志已被外部清理时，归因采用数据库内最早可观测 PV。

内容目录使用增量 upsert，支持 sitemap URL 列表、CSV、JSON；不自动访问第三方 sitemap，也不展开 sitemap 索引。XML 外部实体被拒绝。所有查询使用绑定参数，读写分别校验网站可见与管理权限；分享令牌及 2FA 中间令牌无法访问新增接口。

目录增量导入只更新明确提供的元数据字段；未提供字段保留原值，显式 null 可清空可空字段。sitemap 与仅含 URL 的输入保留已有元数据。日志与目录的路径保留 URL 编码，编码后长度超过 500 字符时明确拒绝；与 Umami 人类浏览数据比较时按上游规则解码一次，已有日志标识与去重指纹保持稳定。

JSON 日志和目录日期接受有效的 YYYY-MM-DD（UTC 日期）、含秒且带 Z 或时区偏移的 ISO 时间，以及非负安全整数的毫秒时间戳。数值 0 或不小于 100000000000 按毫秒解析，较小非零数拒绝秒与毫秒歧义；较早日期可使用 ISO 字符串。无效日历日期、无时区时间与非数值时间戳会被拒绝。combined 日志使用原有日期与时区格式，并校验真实日历日期。

月度 AI 占比固定包含结束日期所在月及此前 5 个月，按当前查询时区确定自然月边界。没有请求的月份保留 null 占比，图表显示空缺。设置保存支持按字段更新并在网站锁内合并；明确保存的空规则数组持续有效。

统计使用 PostgreSQL 持久汇总、精确访问事实与覆盖清单，当前尾部、无效桶和覆盖缺口按原始事实补齐。范围 UV 合并访问事实后去重，访问、跳出与时长保持原有计算规则；未支持的复杂条件使用对应的精确查询。日志分类沿用导入时保存的规则与证据。实现及容量验证方法见 [统计加速](analytics-acceleration.md) 和 [性能说明](performance.md)，实际部署按自己的数据规模与并发验收。

官方范围来源：[OpenAI](https://developers.openai.com/api/docs/bots)、[Perplexity](https://docs.perplexity.ai/docs/resources/perplexity-crawlers)、[Google](https://developers.google.com/crawling/docs/crawlers-fetchers/verify-google-requests)。范围来源和下载时间记录在 config/liekan/bot-ranges.json。

新访客占比按窗口内新建匿名标识估算，无法证明真实首次访问。内容偏好按机器人在已分类目录中的请求集中度计算，未分类 URL 仍包含在全部请求分母。趋势采用前一等长窗口，前期为零时显示未定义。新鲜度字段显示导入的更新日期距统计结束日期的天数；缺少更新日期时显示未观测。抓取深度使用目录上传的链接深度；缺少字段时保留待接入。重复率缺少明确重复判定证据，保留待提供。

扩展表与 `website` 之间保留网站 UUID 的删除级联外键，防止网站删除后 UUID 被复用导致旧数据泄露；该约束由 Liekan 自有迁移维护。迁移 `014_website_site_number.sql` 为 `website` 追加展示与导航用的 `site_number` 列、序列及唯一索引，采集与统计仍使用网站 UUID。重置网站统计在同一事务中清除 Liekan 日志与导入记录，保留目录和策略配置。写事务锁定网站并重新检查当前用户与团队权限。

实时访问流在进入、重新进入或主动刷新时读取最新 30 天内的已入库请求，本轮读取后固定窗口；静置、切换标签页和恢复网络保持本轮结果。手动选择历史日期后保持所选范围。完整日志每页 100 条，使用时间与记录 ID 的游标前后翻页，URL 保存日期、搜索、分类与游标；旧的仅 page 参数请求仍可兼容。搜索采用字面匹配，百分号和下划线作为普通字符处理。规则更新只作用于随后导入的记录，历史记录沿用导入时的分类。

## 补充 UI 统计口径

- 留存按所选期间首次访问日期入组，基于已完整观察的队列加权汇总；未观察与零返回率分别展示。关联访问使用相同日期、队列和排除跳出筛选。
- 归因按独立转化访客合并，保留首次/末次来源模型；关联会话绑定相同模型与转化条件。
- 旅程先合并访问内相邻重复节点，再依据类型、步数、开始与结束节点形成路径；指定终点必须出现在所选步数范围内，超限路径排除；详情使用相同序列和筛选。
- 性能分位数只统计所选指标的非空样本；CLS 无时间单位，其他指标采用毫秒或秒明确标注。收入按所选币种统计，金额保留精度，不执行汇率换算。来源与渠道归因使用所选期间每个匿名 session_id 的首事件，按 created_at、event_id 稳定排序且每会话只贡献一次收入；事件条件用于选择符合条件的会话，归因仍取该会话在期间内的首事件。
- 链接明细按来源与国家联合汇总实际点击事件；像素请求计数包含代理与缓存影响。
- 完整导出逐页读取，敏感属性、邮箱、IPv4、IPv6 和凭据脱敏，访问标识在单份导出内一致匿名化；CSV 公式单元格加保护。配置导出不包含账户密钥、分享密码或原始 IP。

完整导出在主库的一致性快照内读取汇总、维度和全部分页明细。持续采集产生的新记录在下一次导出中出现，当前文件各分页和计数使用同一快照。浏览器、设备和国家维度以发生页面访问的访客计数。


### 来源关键词

来源渠道下的“来源关键词”按会话的首次浏览事件归属搜索引擎。入口可以早于所选日期，浏览量、跳出和目标转化只计算所选范围。搜索渠道归类沿用 UTM 来源与媒介优先的现有规则；每个 `(visit_id, session_id)` 只归入一个关键词行，重复触发目标仍只算一个转化会话。

匹配已支持搜索引擎的搜索页面与参数后，优先使用来源搜索词；缺少可用搜索词时使用已采集的 `utm_term`，标注为手动标记。来源词脱敏后仍可使用通过隐私校验的 UTM 词；两者均无可用词时保留相应状态。百度、搜狗、360 的来源查询遵循显式 `ie` 编码声明；未声明时先严格解析 UTF-8，再尝试 GB18030。声明冲突、未知编码或不合法字节均保留不可用状态，并允许合法 UTM 回退。不同引擎的来源证据分别保留；引擎冲突、参数冲突、解析失败、完整性无法确认、来源未携带搜索词、跳转链接无可用搜索词、来源格式不支持、已脱敏分别统计。邮箱、IP 和可识别凭据格式在页面与导出中统一脱敏。站内搜索、AI 对话及非搜索渠道不参与本报告。

关键词可用率为“来源搜索词会话 + UTM 关键词会话”除以搜索渠道会话。未配置转化目标时转化率为空；搜索会话为零时可用率与占比为空，有搜索会话且无可用关键词时可用率为 0。引擎筛选同时作用于指标卡与明细；关键词、依据和状态筛选仅作用于明细，占比分母保留所选引擎的全部搜索会话。

关键词导出共享统计计算预算，进入计算槽后的总计算预算为 60 秒，每条数据库语句使用剩余预算。调整关键词识别规则时应升级关键词共享缓存版本，避免继续复用旧规则的聚合结果。

筛选、稳定排序在服务端分页前完成，每页 20 行。翻页携带统计快照标识；聚合内容或指标发生变化后回到第 1 页并提示，相同数据重新读取保留页码。关键词使用专用 `page-report` 协议，完整 `report` 接口保留原有图表契约。完整 CSV 使用新的可重复读快照，包含读取时间、日期、时区与筛选条件，导出全部匹配行。搜索候选证据最多 100,000 组、50 MiB，CSV 最多 100,000 行、50 MiB；超限明确报错，需缩小范围。

本报告支持 PostgreSQL，要求完整登录与网站访问权限。来源词参数缺失或为空时，显示“来源未携带搜索词”（`missing`）。百度、360、搜狗的已支持来源主机上的 `/link` 跳转链接没有非空搜索词参数时，单独显示“跳转链接无可用搜索词”（`redirect`）；其他不受支持的主机、路径或编码保留“来源格式不支持”（`unsupported`）。截断证据优先显示“完整性无法确认”。有效的 `utm_term` 仍可作为手动标记回退，所有不可用状态的会话继续计入搜索流量分母。历史记录中未采集或截断的搜索词无法恢复。当前功能使用已有采集字段，不增加数据库迁移或采集脚本参数。

新版关键词页面和导出请求声明 `keywordStatusVersion=2`；显式筛选 `status=redirect` 也表示支持新状态。未声明能力的旧请求沿用 `unsupported`，跳转会话与同一引擎的其他不支持来源在筛选和分页前合并。投影保留空关键词及原始会话、跳出和转化总量，缓存中的新分类保持独立，防止部署时已打开的旧页面出现空白状态。

状态文字查询保留“未提供”“来源不支持”别名。已有查询链接在新版页面和导出中继续命中对应状态；“来源不支持”包含原来归入该状态的跳转来源及其他不支持来源。

### 搜索引擎与 AI 搜索

来源渠道下的“搜索引擎”复用首次浏览来源与 `(visit_id, session_id)` 会话统计，按已有 UTM 来源、媒介优先规则区分传统搜索与 AI 搜索引荐。统计包含搜索词缺失的搜索会话；直接访问、其他引荐与爬虫日志不参与。平台的不同子域名与已支持别名合并，例如 ChatGPT 的两个域名、Kimi 的两个域名。

搜索总会话等于传统搜索会话与 AI 搜索引荐会话之和。AI 搜索占比与明细的搜索总占比分母为搜索总会话；两个饼图及明细的同类占比分别使用传统搜索、AI 搜索引荐会话为分母。类型筛选与排序仅影响明细，图表保留完整类别，图例无法隐藏类别后改变占比分母。明细包含会话、范围内 PV、跳出率与任一目标的去重会话转化率，指标从原始计数合并计算；缺少目标时转化率为空，零搜索会话时占比为空。页面使用已有私有分页统计接口与完整登录、网站访问权限校验，无新增数据库迁移。平台明细行数由已支持平台目录限制，导出包含全部匹配平台。

### 抓取页面筛选

抓取页面支持按记录中的爬虫类型和具体爬虫身份组合筛选。筛选在页面聚合与分页前生效，页面数、抓取次数、主力蜘蛛、最近抓取、目录分布、目录盲区及抓取清单导出使用相同条件。具体爬虫选项来自所选日期及身份核验范围内的 AI 抓取记录；官方身份按爬虫 ID 匹配，自定义及历史未映射记录按名称匹配并限定无官方身份。类型筛选继续使用现有 AI 抓取统计口径，未产生符合该口径记录的类型显示空结果。切换类型清空具体爬虫，切换筛选回到第一页，刷新和浏览器前进后退保留 URL 中的条件。

抓取页面明细的“标题”来自同一路径的内容目录标题，缺失或空白时显示“未提供”，保留原始标题语言。抓取热度沿用所选范围最高抓取量为 100 的计算口径，以数值展示。主力蜘蛛按当前筛选范围内每个页面的抓取次数降序展示前两名，同量时按名称、身份 ID 稳定排序；官方与自定义身份保持分离，身份说明可通过悬停查看。标题及两名主力蜘蛛同步进入抓取清单导出；页面 URL 使用已有安全链接规则在新标签页打开。
